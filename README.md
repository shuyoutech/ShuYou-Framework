# ShuYou-Framework

ShuYou-Framework微服务脚手架，采用SpringBoot4.0、SpringCloud2025、Alibaba2025等框架，开发的一套SpringCloud开发平台，旨在为开发者提供一个简洁、高效、可扩展的代码开发平台
